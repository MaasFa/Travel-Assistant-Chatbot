# ✈️ Travel Assistant Chatbot

A domain-specific AI chatbot designed to provide **real-time travel assistance** to users — built using **Botpress**, a no-code/low-code conversational AI platform. Users can type freely in natural language and receive intelligent responses about destinations, itineraries, and hotel recommendations.

🔗 **[Try the Live Demo](https://cdn.botpress.cloud/webchat/v2.2/shareable.html?configUrl=https://files.bpcontent.cloud/2025/01/27/13/20250127130209-PCWHPWT4.json)**

---

## 📌 What It Does

The Travel Assistant helps users with:

- 🗺️ **Destination Guides** — information about popular travel destinations
- 📅 **Itinerary Suggestions** — day-by-day travel plans based on user interest
- 🏨 **Hotel Recommendations** — suggestions based on destination and preference
- 💬 **General Travel Q&A** — answering common traveller questions in natural language

## 💬 How to Use

1. Click the **[Live Demo link](https://cdn.botpress.cloud/webchat/v2.2/shareable.html?configUrl=https://files.bpcontent.cloud/2025/01/27/13/20250127130209-PCWHPWT4.json)**
2. Type your travel query in natural language
3. The bot responds with relevant travel information

### Example queries you can try:
```
"Suggest a 3-day itinerary for Manali"
"What are the best hotels in Goa?"
"What should I pack for a trip to Ladakh?"
"Tell me about Rajasthan as a travel destination"
"Best time to visit Kerala?"
```

---

## 🧠 How It Works

The chatbot uses **Botpress's built-in NLU (Natural Language Understanding)** engine to:

1. **Understand intent** — classify what the user is asking (destination info, hotel rec, itinerary etc.)
2. **Extract entities** — identify location names, dates, preferences from free-text input
3. **Trigger flows** — route the conversation to the appropriate response flow
4. **Generate response** — return a contextually relevant travel answer

All conversation flows, intents, and responses are configured inside the Botpress visual editor — no backend code required.
